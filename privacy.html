Privacy Policy

English / 日本語 (below). Last updated: 2026-10-31

1. Who we are

Topic Scoreboard is a private, single-user desktop tool operated by an individual YouTube creator. It is not offered to other users. Contact: reiwork4650@gmail.com

2. YouTube API Services

This tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data we access

  • Public, non-authorized YouTube data only: search results, video titles/descriptions, view/like/comment counts, channel subscriber counts, and public comments (YouTube Data API v3: search.list, videos.list, channels.list, playlistItems.list, commentThreads.list).
  • The tool does not request access to any Google account and does not use OAuth login.
  • Non-YouTube sources: Wikipedia page views, news headlines, and text the creator pastes by hand.

4. Personal data

We do not store commenters' names, channel IDs, profile images or any other profile data. Only the comment text needed to count topic mentions is kept, and only for the retention period below.

5. Storage and retention

  • All data is stored locally in a SQLite file on the creator's PC. It is not uploaded, sold, shared or published.
  • Titles, descriptions and comment text are deleted or refreshed within 30 days.
  • Statistics (view, like, comment, subscriber counts) are deleted within 30 days. If YouTube grants the additional policy for derived metrics and data storage, statistics and derived metrics are kept for up to 36 months and then deleted.

6. Use of data

Data is used only to rank candidate video topics for the creator's own channel and is shown only to the creator inside the tool. Values calculated by the tool are labeled "calculated by this app" and are kept separate from values returned by YouTube.

7. Deletion and revoking access

The tool holds no data about other people beyond the public data above, so there is no account to delete. To ask for deletion of any data, contact reiwork4650@gmail.com; the creator can also delete the local data file at any time. If the tool ever requested access to a Google account, it could be revoked at https://security.google.com/settings/security/permissions.

8. Changes

This policy may be updated; the date above shows the latest revision.
