Topic Scoreboard

English / 日本語 (below)

About

Topic Scoreboard is a private, single-user desktop tool used by one YouTube creator (Japan) to plan Japanese-language explainer videos about an anime franchise. Once a week it ranks candidate video topics by combining public demand signals (Wikipedia page views, news headlines) with public YouTube data, so the creator can decide what to make next.

  • Not sold, not offered to other users, not publicly accessible, no ads, no revenue.
  • Number of users: 1 (the developer, who is also the channel owner).
  • Data is stored only on the creator's own PC. Nothing is uploaded or shared.

YouTube API Services

This tool uses YouTube API Services (YouTube Data API v3, public data only). By using the tool, the user is bound by the YouTube Terms of Service. See also the Google Privacy Policy and our Privacy Policy.

Values returned by the API are labeled "YouTube data" in the tool; values calculated by the tool are labeled "calculated by this app" and are shown only to the creator.
